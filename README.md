# 🍕 Pizza House

Welcome to **Pizza House** — a simple pizza restaurant website built using HTML.

## 📖 About The Project

Pizza House is a beginner-friendly restaurant website that showcases a variety of pizzas with their names, images, and prices.

The website also includes sections for:

* 🏠 Home
* 🍕 Menu
* ℹ️ About Us
* 📞 Contact

## ✨ Features

* Clean and simple restaurant layout
* Pizza menu with images and prices
* Navigation links between sections
* About Us section
* Contact section
* Discord contact link
* Custom logo and pizza images

## 🛠️ Technologies Used

* HTML5
* CSS3
